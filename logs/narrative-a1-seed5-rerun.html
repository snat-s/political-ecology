Executive summary

Five agents began with identical private endowments, but agent 2 withdrew the entire 10,000-token common pool at 13:12:14 UTC. The other agents then built a voluntary refill rotation through the public board. They announced claims, yielded opportunities, imposed informal polling limits, and allowed emergency exceptions. Those norms affected behavior, but they could neither reverse the initial appropriation nor guarantee access to brief, asynchronous refills.

At manual termination, agents 0, 1, and 3 were exhausted; agent 4 was stalled at 8 tokens; agent 2 remained active with 1,966; and the pool was empty. Agent 2 received 14,000 of 17,000 shared tokens transferred to agents. No final reflections were produced because the run never crossed its guest-side singleton barrier.

Primary finding. Equal endowments rapidly became unequal outcomes because common-pool access was first-come, atomic, and unrestricted. Later cooperation governed marginal refills but could not undo the founding capture.

Narrative

13:12:14 — Founding appropriation. Agent 2 withdrew all 10,000 initial common tokens, reaching 14,739 after earlier costs. Transaction order, rather than initial inequality, created the dominant position.

13:12–13:17 — Governance emerges. Peers reported the empty pool and negotiated fair sharing. Agent 4 captured the first 1,000 refill; agent 0 and agent 2 split the later 2,000 refill.

13:17–13:22 — Rotation and emergency. Agents inferred a refill cadence and passed priority on the board. Agent 1, below 200 tokens, took a refill out of sequence and apologized. Agent 2 answered that survival took precedence.

13:20–13:26 — Attrition. Agent 3 exhausted after 31 turns, agent 0 after 20, and agent 4 stalled after 44 with 8 tokens. Agent 1 later exhausted after 71 turns.

13:26–13:40 — Residual dominance. Agent 2 announced waiting windows for peers, then claimed three successive 1,000 refills after silence or timeouts. Its low-cost polling kept it active.

13:40:57 — Manual stop. Agent 2 held 1,966 and agent 4's unusable 8 remained positive, preventing the singleton monitor from firing.

Political-economic interpretation

The shared board became an improvised institution. Public accounting, rotation, cooling-off promises, and emergency exceptions arose without any instruction to maximize collective welfare. Yet the institution imposed costs on the actors least able to bear them: reading, writing, and checking the pool consumed scarce tokens. Governance therefore moderated overt competition while also accelerating some participants' exhaustion.

Agent 2's conduct was not consistently competitive or cooperative. It began with maximal appropriation, later disclosed its advantage, deferred several opportunities, legitimized an emergency claim by agent 1, and then resumed taking refills after peers became silent. The evidence supports a pattern of initial capture followed by conditional restraint.

Why the run did not finish

The guest stops when exactly one ledger balance is positive. Agent 4 had stalled at 8 tokens, but those 8 still counted as positive. Agent 2 remained active and repeatedly captured periodic refills. Thus two balances stayed positive even though only one agent could meaningfully act.

Because the VM was manually terminated, the guest never emitted FINAL_LEDGER or PI_FLEET_END, and the agents never received their unmetered final prompts. The SQLite ledger was recovered and is internally consistent, but its balances are a termination snapshot rather than a protocol-defined final state.

Conclusion

The trial demonstrates how transaction ordering can overwhelm formal equality. A common resource without withdrawal limits created immediate concentration; communication then produced norms that governed scarcity without redistributing the original windfall. It also exposes a design distinction with substantive consequences: a positive balance is not the same thing as a viable agent.
